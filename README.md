# Al Francis B. Paz - Personal Portfolio

Welcome to the repository for my personal portfolio website! This site showcases my background, education, projects, internships, and technical skills as a Computer Engineering graduate from Ateneo De Naga University.

## Overview

This is a fully responsive, static website built from scratch using vanilla web technologies. It features a modern, dynamic UI with dark/light mode support, interactive carousels, and a sleek design tailored to highlight my journey between hardware and software development.

### Key Features

*   **Dark/Light Theme Toggle:** A custom, animated theme switcher to accommodate user preferences.
*   **Fully Responsive Design:** Optimized for both desktop and mobile viewing.
*   **Dynamic Typing Effect:** An engaging hero section that highlights my different roles (Backend Developer, Android Developer, Software Engineer, etc.).
*   **Interactive Galleries & Carousels:** Custom-built infinite scrolling carousels and modal lightboxes to showcase project images and event photos seamlessly.
*   **App Builders PH Integration:** A live upvote widget for my app, Ride.ADNU.

## Built With

*   **HTML5:** For semantic structure and accessibility.
*   **CSS3:** For styling, custom animations (`@keyframes`), CSS variables for theming, and responsive layouts (Flexbox/Grid).
*   **JavaScript (Vanilla):** For DOM manipulation, theme management (using `localStorage`), smooth scrolling, and dynamic gallery interactions.
*   **Google Fonts:** Utilizing *Inter* and *Outfit* for modern typography.
*   **FontAwesome (v6.4.0):** For crisp, scalable vector icons.

## Project Structure

*   `index.html` - The main HTML document containing all sections (Hero, About, Education, Projects, etc.).
*   `styles.css` - The core stylesheet including theme variables, animations, and responsive media queries.
*   `script.js` - The main JavaScript file handling navigation, theme toggling, typing effects, and gallery lightboxes.
*   Assets (Directories) - Various folders like `Projects/`, `Events/`, `Internships/`, `Certifications/` containing images and PDFs showcased on the site.
